# 🧮 OmniCalc — Next-Gen Precision Calculator

A precision calculator application featuring standard & scientific calculation modes, glassmorphic UI, dynamic themes, Web Audio feedback, memory storage, and calculation history.

## ✨ Features

- **Dual Modes**: Seamless toggle between **Standard** arithmetic and **Scientific** functions (`sin`, `cos`, `tan`, `sin⁻¹`, `cos⁻¹`, `tan⁻¹`, `ln`, `log`, `√`, `x!`, `xʸ`, `x²`, `π`, `e`, DEG/RAD toggle).
- **Calculation History Drawer**: Keeps track of recent equations with timestamps, click-to-recall, and local storage persistence.
- **Memory Operations**: Full memory controls (`MC`, `MR`, `M+`, `M-`, `MS`) with an active memory indicator.
- **Audio & Haptic Feedback**: Synthesized clicks generated via the native Web Audio API (with sound toggle).
- **Multiple Aesthetic Themes**:
  - 🌌 *Aurora Dark* (Default glassy indigo/teal)
  - 🌑 *Deep Midnight* (OLED dark blue)
  - ⚡ *Cyber Neon* (High-contrast magenta & cyan)
  - ☀️ *Crystal Light* (Frosted pearl light mode)
- **Real-Time Live Preview**: Dynamically computes results as you type.
- **Copy to Clipboard**: Quick copy button with visual toast confirmation.
- **Full Keyboard Support**: Complete control without touching the mouse.

## ⌨️ Keyboard Shortcuts

| Shortcut | Description |
| :--- | :--- |
| `0` – `9`, `.` | Numeric input and decimal point |
| `+`, `-`, `*`, `/` | Basic arithmetic operators |
| `Enter` or `=` | Calculate result |
| `Backspace` | Delete last character / token |
| `Escape` or `c` | Clear all (`AC`) |
| `(` `)` | Parentheses |
| `^` | Exponentiation (power) |
| `%` | Percentage |
| `h` | Toggle History drawer |
| `s` | Toggle Scientific mode |

## 🚀 Getting Started

Simply open [`index.html`](index.html) in any modern web browser — no dependencies or build steps required.

```bash
# Clone the repository via SSH
git clone git@github.com:krishnask-17/CALCULATOR-BY-ANTIGRAVITY.git

# Navigate into the folder
cd CALCULATOR-BY-ANTIGRAVITY

# Open in browser
start index.html
```
